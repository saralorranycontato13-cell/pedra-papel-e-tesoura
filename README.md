# Título do jogo: RPS Mon 
Equipe: 
+ Isaac Samuel
+ Sara Lorrany 


## Narrativa/tema: 
O jogo se passa em uma cidade Pokémon chamada Viridian, onde o player deve encontrar os Pokémon para conseguir conquistar eles, se tornando o rei Pokémon! 

## Objetivo do jogo: 
O objetivo principal é conquistar os Pokémon, através de um jogo de pedra, papel e tesoura.

## Ações do jogador:
O jogador vai se mover usando W, S, D e A do teclado, vai interagir com os Pokémon abrindo uma cena em primeira pessoa para jogar Pedra, Papel e Tesoura.

## Inimigos e/ou obstáculos:
Os inimigos serão os próprios Pokémon que o jogador precisa coletar, eles vão surgir aleatoriamente pela cidade e vão jogar com um bot o pedra, papel e tesoura.

## Itens e coletáveis:
As insígnias que dropaw dos Pokémon que perderem um melhor de três para o player. 

## Condições de vitória: 
Ganhar 4 insígnias.

## Condições de derrota:
Perder 3 rodadas de pedra, papel tesoura. 

## Progressão/dificuldade:
São as cidades que mudam.

Referências visuais/estéticas:
O anime/jogo de Pokémon.
